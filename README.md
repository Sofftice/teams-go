# teams-go

A Microsoft Teams client written in Go using Qt, designed to reduce UI clutter, be smaller, more
performant and provide Linux support.

This project would not exist if Microsoft actually made well-designed user-focused software. With
Sofftice, we try to bring back that old soft Office that worked out of the box. If you find issues
or just have some questions, use the issue tracker.
